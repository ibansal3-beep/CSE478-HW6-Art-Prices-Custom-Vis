02 / CURATOR'S NOTE

What makes a work
valuable?

There is no single answer in these records. Works created in the same year or assigned to the same movement can carry very different prices.

This exhibit invites you to notice the variation rather than assume that age or style determines worth. The flowers reveal patterns within the selected data, not a universal formula for artistic value.

03 / DESIGN & METHOD

How this exhibit was made

Marks: Each artwork is represented by an original five-petal radial flower glyph with a central disc.

Visual channels: Petal radius encodes recorded price in USD using a square-root scale. Color encodes art movement. Horizontal position encodes creation year, with slight jitter to reduce overlap. Vertical bands encode the dataset's art-period categories.

Interactions: Hover over or focus on a flower to inspect artwork metadata. Use the period filter buttons to display all artworks or one period at a time.

Custom visualization category — combinatorial: This design combines a time-positioned, period-banded visual field with custom radial flower glyphs that encode individual artwork records. The flower geometry is created with SVG paths in D3 rather than using an ordinary bar chart, scatterplot, or stock D3 visualization block.

Dataset: Kaggle, “Art Price Dataset” (artDataset.csv). This exhibit displays 213 artwork records from a working dataset containing numeric prices, creation years, art periods, and art-movement labels.

Data preparation: Price values and creation years are interpreted numerically for the visual encodings. Artwork movements not represented as individual legend categories are displayed as “Other.” The collection is a selected subset and should not be treated as a statistically representative sample of the entire art market.

Implementation: D3.js v7 is used for data loading, scales, SVG construction, custom glyph generation, and interaction. The visualization is implemented in the project's script.js file.

Prices are recorded dataset values, not independently verified auction outcomes or inflation-adjusted estimates. The flower symbols are abstract data marks, not reproductions of the original artworks.
